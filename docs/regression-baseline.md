## 安装与统一检查

从包含源码、测试夹具、Skill、锁文件与工作流的项目根目录执行：

```powershell
uv --version
uv --cache-dir .uv-cache python install 3.12.16
uv --cache-dir .uv-cache sync --locked
uv --cache-dir .uv-cache run --locked python scripts/check.py
```

uv 版本应为 0.13.6。安装解释器和依赖可能需要网络；测试本身使用模拟模型与本地 HTTP 服务，
不需要真实模型密钥。真实 OCR 用例随完整测试执行，不因速度或本地服务限制而跳过。

首次安装和已有解释器／缓存的安装是不同验证条件。已有本地安装命令已执行成功，
全新 GitHub Runner 的解释器下载、依赖下载与 Action 执行仍列为远程待验收。

统一入口依次完成：

1. 核对 Python 与 uv 版本，记录平台和锁文件 SHA-256。
2. 按锁文件同步依赖；同步失败时停止后续检查。
3. 收集测试，并预检本地回环连接。
4. 在独立短系统临时目录运行全量 pytest，保存 JUnit 和慢用例记录。
5. 运行 Ruff 代码检查和格式检查。
6. 核对收集数与实际执行数、失败／错误／跳过数及锁文件完整性，汇总退出状态。

回环预检失败时，入口不会启动全量测试，仍执行 Ruff，最终返回非零退出码。
检查失败后的后续独立检查结果不会覆盖前面的失败。测试数据目录和报告目录分离，避免深报告目录造成 Windows 长路径问题。

## 报告与通过条件

每次报告保存在 `workspace/checks/<本次运行编号>/`，运行结束时控制台打印实际路径。

| 文件 | 内容 |
|---|---|
| `summary.json` | `passed`、环境、命令、退出码、耗时、测试数量和锁文件核对结果 |
| `collect.stdout.txt` / `collect.stderr.txt` | 测试收集清单与错误 |
| `pytest.stdout.txt` / `pytest.stderr.txt` | 完整测试输出、失败原因与慢用例 |
| `tests.junit.xml` | 实际测试结果；未启动 pytest 时不会生成 |
| `ruff-check.*.txt` / `ruff-format.*.txt` | 两项 Ruff 输出 |

单次完整回归通过需要：入口退出码为 0，`passed` 为 true，测试收集与执行数量一致且大于 0，
无失败／错误／跳过，Ruff 两项通过，锁文件未改变。缺报告、空收集或未执行测试不能视为通过。
运行被外部中止时，缺少最终报告也不能推定通过。

JUnit 校验接受单个 `testsuite` 根，或 `testsuites` 根下的多个平铺套件；当前不支持嵌套套件，遇到时明确拒绝。
每个套件的 `tests`、`failures`、`errors`、`skipped` 必须为非负整数，并与实际测试及结果条目一致。
报告若有根汇总属性，也必须与套件合计一致；不允许套件外条目被忽略。

293 是初始固化基线的用例数，不是永久硬编码的门槛；后续变化见顺序修复记录。新增或移除用例后必须解释数量变化，
不能仅靠数量相等判断行为正确；不得删除必要测试、放宽正确断言、自动重跑到成功或忽略退出码。

## 故障处理与 Bug 记录

问题编号、类型、修复状态与验证依据维护在 [Bug 记录](bugs.md)。遇到新问题先保留原始输出、退出码和环境信息，
区分业务缺陷、测试设施缺陷与执行环境限制；失败或中止轮次保留说明，不计入有效通过轮次。

| 现象 | 已确认的处理方式 |
|---|---|
| `.venv` 的基础解释器不存在 | 按 `.python-version` 恢复解释器并执行锁定同步；不切换版本冒充同一基线 |
| 回环连接 WinError 10013 | 让执行环境允许本机回环连接后重新运行完整入口；不跳过本地 HTTP 测试 |
| Skill 快照 FileNotFoundError 且路径很深 | 使用入口生成的独立短临时目录；不把 pytest 数据目录放进深报告目录 |
| 收集数量或报告不一致 | 保留收集清单和 JUnit，查明原因；不修改报告数字使其一致 |

测试设施清理继承的模型与代理配置，在应用配置入口屏蔽项目 `.env`，限制常规 Python socket 外部连接，
并为现有 Python 子进程安装保护。它不覆盖任意外部程序、主动移除钩子的进程或所有文件读取，不是操作系统沙箱。
测试通过不证明真实模型生成质量、真实公开检索服务可用性或所有字数／评分要求都已实现。
