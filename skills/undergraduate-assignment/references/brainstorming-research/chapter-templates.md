# 本科作业分部分组织示例

分部分写作以用户确认的大纲为准。本文件只说明如何把已确认的大纲映射为工作文件，不要求每份作业建立“章节”目录或采用固定论文结构。严格执行 assignment 的总字数、分题字数和统计口径；若 assignment 未给出字数限制，先询问用户。

## 单文件作业

短 Essay、反思作业或其他不需要拆分的交付物，可以只使用一个正文文件。例如：

```text
assignment.md
```

标题和各部分顺序应与已确认大纲一致；不得自动插入摘要、研究方法、创新点、讨论或展望。

## 多部分作业

只有在作业篇幅、交付要求或协作流程需要时，才拆成多个文件。文件名按实际内容命名，例如：

```text
parts/
├── 01-question-one.md
├── 02-question-two.md
└── 03-references.md
```

上例仅展示文件组织方式；题目数量、参考文献是否单列以及文件格式，均按 assignment 和已确认大纲决定。也可以按案例、论点、分析维度或报告模块拆分。LaTeX 交付物可使用 `.tex`；其他格式按提交要求选用。

## 每部分的工作记录

| 项目 | 记录方式 |
|---|---|
| 对应要求 | 指明题目、必答子问题与 rubric 项目 |
| 内容目标 | 写明本部分要回答的问题及核心论点 |
| 证据 | 核查材料真实存在、与论点相关；引用文献须通过 DOI 验证 |
| 篇幅 | 使用已确认的部分预算或分题限制，不给出默认比例和字数 |
| 状态 | 待写、待核查、待用户确认、已确认 |

## 调整和确认

先让用户确认整体大纲，再逐部分写作。每部分完成后展示内容、证据核查情况及实际字数，等待用户确认后再写下一部分。若 rubric 与现有文章内容冲突，暂停受影响部分并询问用户。大纲调整后更新各部分的要求映射和字数预算；复杂作业可将确认结果保存到 `plan/outline.md`。
