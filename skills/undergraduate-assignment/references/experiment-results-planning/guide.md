# 本科作业实验与结果

用于题目确实要求的实验、数据分析、仿真及其图表和结果说明。以 assignment、rubric 和已确认大纲决定内容，不将普通 essay 或 Discussion 标题自动视为需要实验设计的任务。

## 一、接收要求并确定当前范围

沿用[作业要求解析](../brainstorming-research/guide.md)和[流程控制](../paper-orchestration/guide.md)中的题目、评分项、大纲、当前部分、字数限制及确认决定。

开始前明确当前是在规划实验、执行分析、设计图表布局，还是撰写已有结果。优先使用题目提供的数据和方法。数据来源、必需步骤或允许使用模拟数据的范围不清楚且影响作答时，先询问用户。

规划与实际执行分开记录。提出可行实验方案不等于已执行实验，代码已生成不等于已运行，运行成功不等于结果正确。

## 二、按任务选择实验或分析要求

记录能够说明和复核当前工作所必需的信息，沿用现有笔记、代码和结果文件。复杂任务可使用实验记录或数据清单，但不强制创建固定数量的计划、表格或审查文件。

| 内容 | 何时需要及记录什么 |
|---|---|
| 数据与对象 | 使用数据时说明来源、版本、单位、样本范围和必要的清洗或排除规则 |
| 方法与步骤 | 执行实验、分析或仿真时记录所用步骤、参数和选择理由，以课程所需复核程度为准 |
| 数据划分 | 涉及训练、验证或测试时说明划分规则及防止泄漏的处理，不要求无关任务进行划分 |
| 对照或基线 | 题目要求比较，或结论依赖相对效果时，选择合理对象并保持比较条件一致 |
| 指标与统计 | 按问题选择指标，说明单位、计算方式和解释边界；不默认每项任务都需要显著性检验 |
| 重复与不确定性 | 涉及随机性、重复测量或题目要求时，记录重复次数及适用的汇总或不确定性表示 |
| 运行环境 | 环境影响结果或题目要求时记录软件版本、硬件及随机种子，不对所有作业强制列出 |
| 效率、消融、稳健性、泛化或解释性 | 只有题目明确要求，或拟作出的具体结论确需这些证据时才安排 |

Non-IID 构造只适用于涉及该问题的任务，不作为常规必备步骤。不能为达到科研论文的实验规模擅自扩大课程作业。

若用户希望作出超出现有实验支撑的结论，说明缺少哪项验证，询问是否补做或收窄判断；不自动开展超出范围的实验。

## 三、区分三类数据

### 1. 真实观测或实际取得的数据

记录原始数据、测量、题目数据集或官方统计来源，核对对象、时间、单位、分母、样本与版本。自己的计算结果保留输入和实际执行依据，不伪造观测、样本量或运行日志。

### 2. 图表布局占位数据

仅用于展示图表结构的虚构数值，文件名使用 `mock_` 或 `placeholder_` 前缀，图表和配套说明明确标记“布局占位数据，不代表实验结果”。

不能据此评价方法性能或写成“实验结果表明”“已验证”。最终作业如要求真实结果，提交前必须替换并重新检查表格、图注和正文；未替换版本保持草稿状态。只有作业本身明确要求布局演示时，才按已确认要求交付并保留标注。

### 3. 作业允许的仿真或合成数据

当题目或用户已确认的任务确实允许仿真时，可作为正式分析输入或仿真实验结果，不要求一律替换为真实观测。记录生成规则、参数、假设、必要的随机种子及实际运行过程，并标记为仿真或合成数据。

由实际执行的仿真得到的结果可以表述为“在本仿真设置下观察到……”，不能声称是真实世界的实测表现或任意扩大适用范围。仅编造一组方便的数值不能冒充已运行的仿真实验。

作业要求真实数据但用户提出使用模拟数据，或材料对数据类型要求冲突时，暂停说明差异并询问；未明确前不自行替换。

## 四、将问题、结果与判断对应起来

在现有记录中按需维护以下关系，不要求为每个论文章节建立独立文件：

| 题目或评分项 | 分析问题 | 方法或比较 | 数据及实际输出 | 图表或正文位置 | 可支持的判断 | 未解决限制 |
|---|---|---|---|---|---|---|

每项定量判断应能追溯到实际数据或分析输出。相关性、趋势、个案和仿真观察不能未经论证升级为因果关系或普遍结论。

实际数据未取得、计算未执行或证据不足时，说明尚缺什么；暂停依赖这些结果的正文，询问用户是否提供材料、执行所需分析或调整内容。可以继续整理不受影响的计划，但不能填入虚构结果。

## 五、图表和汇总规则

图表应服务于题目、数据呈现或必要的论证，不为凑数量制作。规划时明确目的、行列或坐标、指标、单位、数据来源及需要呈现的比较。

- 记录筛选、清洗、转换和汇总方式，区分样本数、重复次数及误差含义。
- 均值、标准差、置信区间等仅在数据与分析需要时使用，并正确解释；不将它们当作可随意互换的装饰。
- 图表中的数值、坐标、图例和正文描述须与实际数据匹配，不手工修改数值来贴合预期结论。
- 工具按课程或用户要求选择，可使用 Excel、Python、R 或其他适用工具；输出格式、尺寸和分辨率服从交付要求，不强制同时导出 PNG 与 SVG。
- 需要 Python 绘图时参考[数据图表](../figures-python/guide.md)中的相关方法；其中旧有工具、环境和导出格式默认要求不替代本次作业要求。
- 概念图、流程图可参考[示意图](../figures-diagram/guide.md)，不得把无数值依据的示意图当作实验数据图。
- 图注说明测量或模拟对象、条件和数据性质，不把希望证明的结论写成已经证明的事实。

必要时记录图表、数据文件、生成代码或工作簿和输出版本的对应关系，以便修改后同步更新。

## 六、结果与讨论的写法

遵守已确认大纲与[核心写作规范](../writing-core/guide.md)的语言风格。围绕题目说明实际观察、对应数据或图表，以及能够作出的有限判断。

结果部分准确报告数值和现象；讨论解释意义、条件和局限，区分数据直接显示的事实与作者提出的解释。没有模块对照或其他充分依据时，不将改善直接归因于某个组件；没有因果识别依据时，不以先后变化证明因果。

没有对照的任务不强行套用“优于基线”的句式；尚未有结果的规划文本不使用完成时态冒充已执行分析。仿真结果明确其设置和外推限制，布局占位数据不进入真实结果论证。

“实验目的”可以是课程实验报告明确要求的合法内容，应按题目保留。需要清除的是“表位”“回填模板”“讨论提示”“请替换数据”等写作指令和内部计划，不将整类实验报告内容一律禁止。

引用外部方法、数据说明或文献结论时，执行[证据驱动写作](../evidence-driven-writing/guide.md)与[文献处理](../literature-review/guide.md)的核实规则，包括所有引用文献的 DOI 验证。DOI 核实不代替数据和计算检查；必用材料与 DOI 要求冲突时暂停询问。

## 七、检查、字数与用户确认

交付当前部分前检查：

- 是否覆盖对应题目和评分项，数据类型及方法是否符合已确认要求。
- 原始数据、实际计算、图表和正文是否可对应，是否存在未执行却被写成已完成的操作。
- 是否清楚区分真实数据、仿真数据和布局占位数据，结论是否超过证据边界。
- 是否核对单位、样本、汇总方式、比较条件及引用文献。
- 是否按确认口径实际计数，满足总限制及分题硬限制，不默认允许 ±10% 浮动。
- 是否清除内部写作提示，并保留题目要求的实验目的、步骤或其他合法内容。

缺少字数限制或计数口径不明确时返回作业要求解析询问；不能为了呈现完整科研实验而超出限制。内容与评分表实质冲突、关键结果无法核实或必要内容无法在限制内完成时，暂停并给出具体问题供用户决定。

展示当前部分正文、实际字数、数据性质和核实范围，按[部分写作](../writing-chapters/guide.md)请求用户确认。用户反馈修改后重查受影响的数据、图表、结论和字数，确认前不进入下一部分。实质改变已确认内容时重新确认受影响部分，最后由流程控制模块进行全文检查。
