# 本科作业示意图

为 assignment 制作流程图、架构图、概念图、组织图或时间线。先确认图件是否为必交内容、它要回答的题目，以及课程对语言、尺寸、文件格式和清晰度的要求。图中每个事实、步骤、参数和关系都应有课程材料、用户资料或已核查来源支持；不凭空补充研究结果。

## 一、图件类型

| 图表类型 | 适用内容 |
|---|---|
| 流程图 | 步骤、分支、循环与决策 |
| 架构图 | 系统、模型或模块之间的组成和连接 |
| 概念图 | 理论、概念与因果或分类关系 |
| 组织图 | 层级或职责关系 |
| 时间线 | 已核查事件的先后顺序 |

折线图、柱状图、散点图等有精确数值的数据图表交给 `figures-python` 或作业指定的工具处理。示意图中的数值、时间和模型参数同样须核查来源。

## 二、制作前检查

1. 读取 assignment、rubric、已确认大纲和相关材料，确定图件的任务、位置及需要表达的信息。
2. 列出全部节点、连线、箭头方向、分支条件和文字标注；对不明确但会影响图意的信息询问用户。
3. 确认目标语言、交付格式、页面或展示尺寸、颜色及无障碍要求。未规定时，以最终交付物中的可读性为准，不套用期刊配色或固定 DPI。
4. 确认用户要直接得到可用图件，还是只需要给其他绘图工具使用的提示词。若用户要求图件且当前工具可制作，完成实际文件并检查；仅请求提示词时交付提示词。

## 三、可复用的图件说明

```text
图件类型：[流程图／架构图／概念图／组织图／时间线]
作业中的作用：[对应题目、评分项或正文部分]
主题：[图件标题]
节点：[逐项列出，并写明来源]
关系：[方向、条件、层级或时间顺序]
标注语言：[按作业要求]
输出要求：[格式、尺寸、分辨率及插入位置；未规定则按交付物可读性决定]
配色与形状：[优先遵循课程模板；同时用文字、线型或形状区分关键信息]
```

流程图应明确起点、终点、判断分支与返回路径。架构图应标明模块名称、输入输出和已确认的参数。概念图应区分“相关”“组成”“导致”等不同关系，避免把推测画成已证实的因果关系。时间线应核对事件日期或顺序。

## 四、输出与核查

可根据作业要求使用 Mermaid、SVG、演示文稿形状、绘图软件或其他可编辑方式；需要图像生成提示词时，以上述说明为基础编写。工具选择服从交付格式和图中文字的准确性，不预设某一种生图服务。

生成后打开实际图件，检查文字、箭头、节点对应关系、裁切、颜色对比及插入作业后的可读性。若课程要求特定像素、DPI 或文件格式，按该要求验证；未要求时不预设固定分辨率。报告图件文件路径或提示词、已核查的信息及仍待用户确认的内容。
