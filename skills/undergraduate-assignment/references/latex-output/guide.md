# 本科作业 LaTeX 输出

将已确认的作业大纲和内容制作成符合 assignment 的 LaTeX 交付物。先依据 assignment brief、rubric、教师说明及用户提供的模板确定格式；模板与作业要求或已有文章内容冲突时，暂停受影响部分并询问用户。不要套用学位论文或期刊论文的默认章节。

## 适用与输入

在以下情况使用：作业明确要求 LaTeX；用户明确选择 LaTeX；用户提供需要使用的 LaTeX 模板。若作业规定其他交付格式，先按该规定处理；用户选择与规定冲突时，说明冲突并询问用户。

读取已确认的大纲、字数限制及统计口径、引用格式、交付文件类型和已有内容。大纲未确认时不开始正文写作；每完成一个部分，展示内容并等待用户确认后再进入下一部分。

## 模板与项目检查

1. 查找用户提供或现有项目中的 `.tex`、`.cls`、`.sty`、`.bib`、图片和编译配置；不要求放在固定的 `latex-templates/` 目录。
2. 按 [模板解析指南](template-parser.md) 识别主文件、文档类、所需宏包、命令、章节层级、参考文献方式、编译引擎和输出要求。
3. 保留模板已有结构和必要文件，在其允许范围内填入已确认大纲。仅在 assignment 需要时添加摘要、封面、目录、附录或特定声明；不自动生成这些内容。
4. 若没有模板，按作业语言、内容和提交要求选择合适的简单文档类，并说明所作选择。不强制使用 `article`、`ctexart` 或某一套引用样式。
5. 对缺失且阻止编译的模板文件，先核查现有项目是否已有替代文件；无法补全时向用户说明具体缺项和可行方案。

## 输出组织

可以使用单个 `main.tex`，也可以在实际需要时按已确认大纲拆成多个 `.tex` 文件。主文件名、目录、图片位置和文件命名服从用户提供的模板与项目，不强制创建 `chapters/`、`figures/`、`plan/` 或 `references.bib`。

`\section`、`\subsection`、`\chapter` 等命令是否可用，取决于文档类及模板。只按确认的大纲设置标题，不根据 Markdown 的标题层级机械转换成 `\chapter`。转换正文时检查特殊字符、公式、表格、代码、交叉引用和图片路径；中文编译引擎与字体选择以模板和实际环境为准。

## 引用与证据

引用格式和参考文献工具由 assignment 或模板决定。若使用 BibTeX 或 BibLaTeX，复用项目现有配置；确实需要时再创建或更新 `.bib` 文件。不得用虚构条目填充参考文献。每条引用文献都必须通过 DOI 验证，并核查原文是否支持对应论点；核验不到 DOI 或来源与论点不符时，依照文献模块暂停处理。课程材料、案例或数据另按其来源类型核查，不把格式正确等同于证据真实。

## 编译与检查

1. 使用模板说明或现有项目配置指定的编译方式；未指定时根据文档类、字体和参考文献配置选择兼容的编译链。
2. 编译实际主文件，检查报错、缺失文件、未解析的引用和交叉引用。只有编译成功才能报告“可编译”。
3. 打开生成的交付文件，检查页边距、标题层级、中文字体、图表、公式、参考文献及页面溢出。格式符合模板不能仅凭源码判断。
4. 按已确认的字数统计口径核对最终交付版本。LaTeX 源文件的简单字符数不能直接代表提交系统的统计结果；若无法按指定方式计数，明确说明未验证。
5. 修改后重新编译并检查最终版本。记录实际使用的主文件、编译方式、输出位置和未解决的问题；不强制写入固定的 `plan/notes.md`。

## 交付

说明实际生成了哪些文件、编译与视觉检查结果、字数核查结果，以及尚未解决的模板或格式问题。不要把示例结构、编译命令或引用样式当成 assignment 的要求。
