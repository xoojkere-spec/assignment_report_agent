# 本科作业 LaTeX 模板解析指南

本文件配合 `guide.md` 使用。解析用户提供的模板或现有项目，提取真实要求并映射到已确认的作业大纲；不根据学校、期刊或文件名推断必须采用论文结构。

## 一、确定模板来源与优先级

先读取 assignment brief、rubric、教师补充说明和用户已确认的格式要求，再检查模板文件。模板中存在封面、摘要、致谢、声明等命令，只说明模板支持这些元素，不代表本次作业必须填写。若模板要求与 assignment 或现有文章内容冲突，列明具体位置并询问用户后再处理受影响部分。

模板可以位于任意用户指定目录或现有项目中；不强制扫描 `latex-templates/`。确认哪些是原始模板文件，尽量在工作副本或独立内容文件中编辑，保留可回退的原始版本。

## 二、查找项目入口

检查文件列表和模板说明，找出：

| 对象 | 需要确认 |
|---|---|
| 主 `.tex` 文件 | 实际编译入口、`\documentclass` 与 `\begin{document}` |
| `.cls` / `.sty` | 自定义命令、宏包依赖、字体、版式和可用标题层级 |
| 子文件 | `\input`、`\include`、图表及其他相对路径 |
| 参考文献 | BibTeX、BibLaTeX、手写列表或其他课程指定方式 |
| 构建配置 | 模板说明、`latexmkrc`、编译引擎与实际输出文件 |
| 提交格式 | 是否提交源码、PDF、全部依赖文件或指定文件名 |

不能只凭 `.cls`、`.sty` 或目录名称断定模板类型，也不能假定每个模板都有独立主文件或参考文献数据库。

## 三、提取与大纲有关的约束

识别文档类允许的 `\section`、`\subsection`、`\chapter` 等层级，以及模板的自定义标题命令。查看标题、作者信息、摘要、关键词、目录、图表、公式和附录是否有专用环境。将 assignment 的必答问题和已确认大纲逐项映射到可用命令；可用命令不等于必填内容。

记录课程要求的页边距、字体、行距、页码、引用格式、图表格式和参考文献样式。模板没有明确规定的项目，不自行套用学位论文或期刊规范。需要增加或删除模板原有结构时，先判断是否会影响编译或违反作业要求。

## 四、参考文献与字数

按模板现有方案处理引用。例如 `\bibliography{...}` 指向 BibTeX 数据库；`\addbibresource{...}` 通常与 BibLaTeX 配合。只有作业确实需要时才建立 `.bib` 文件。每条引用文献必须通过 DOI 验证，并核查是否支持相应论点；不得复制模板里的示例文献作为真实引用。

记录 assignment 的字数上限、下限、统计单位和计入范围。模板自带摘要、图注、脚注或参考文献时，按已确认口径判断是否计入。没有字数限制时先询问用户；不能从模板示例推断允许篇幅。

## 五、解析失败与验证

模板文件缺失时，指出确切文件及引用它的位置，检查项目中是否有对应替代文件；无法判断时询问用户。编码、字体或宏包错误应以实际编译日志为依据，不预设是某种错误。若主文件不明确，列出候选及判断依据并请求用户选择。

解析完成后编译主文件，并检查输出中的布局、字体、图表、公式与引用。编译和视觉检查分别报告结果；未能编译时不声称模板适配完成。若用户提供的模板与作业要求存在未解决的冲突，暂停受影响的输出。
