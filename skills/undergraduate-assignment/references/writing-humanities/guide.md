# 文科写作专项

本技能用于本科人文社科作业。先读取 assignment、rubric 和已确认大纲，再选择适用的论证方式；下列论文写法是可用工具，不是必备结构。

## 一、文科论文特点

### 与理工科的区别

| 方面 | 理工科 | 文科/社科 |
|------|--------|-----------|
| 核心 | 实验数据、技术方法 | 论证逻辑、理论分析 |
| 结构 | IMRAD标准结构 | 灵活多样 |
| 图表 | 数据图表为主 | 概念图、流程图为主 |
| 引用 | 侧重近5年文献 | 可追溯经典文献 |
| 语言 | 简洁客观 | 可适度文学化 |

### 常见文科论文类型

- **文学评论**：作品分析、文学理论应用
- **历史研究**：史料分析、历史事件解读
- **哲学论文**：概念辨析、逻辑论证
- **教育研究**：教学实践、教育理论
- **社会学研究**：社会现象分析、调查研究

## 二、论证结构

### 常用论证模式

**总-分-总结构**
```
引出论点 → 分论点1 + 论据 → 分论点2 + 论据 → 分论点3 + 论据 → 总结升华
```

**递进式结构**
```
现象描述 → 原因分析 → 深层探讨 → 解决方案/理论建构
```

**对比式结构**
```
观点A阐述 → 观点B阐述 → 比较分析 → 综合评价 → 自己立场
```

**问题导向结构**
```
提出问题 → 文献回顾 → 理论框架 → 分析论证 → 回答问题
```

### 论证要素

**论点（Thesis）**
- 明确、具体、可论证
- 避免过于宽泛或绝对化
- ❌ "鲁迅很伟大"
- ✅ "鲁迅杂文中的讽刺手法体现了其批判现实主义精神"

**论据（Evidence）**
- 文本证据：原文引用、作品分析
- 理论支撑：学术观点、理论框架
- 事实依据：历史事件、统计数据、案例

**论证（Argument）**
- 逻辑推理清晰
- 论据与论点紧密关联
- 避免逻辑跳跃

## 三、写作风格

### 学术语言特点

**客观性**
- ❌ 我认为这部作品非常感人
- ✅ 该作品通过细腻的心理描写引发读者的情感共鸣

**准确性**
- ❌ 很多学者都这样认为
- ✅ 指明经过核查的具体作者、著作及相关论述，并说明这些论述怎样支持本段观点

**规范性**
- 使用学科专业术语
- 避免口语化表达
- 保持人称一致（通常用第三人称或"本文"）

### 文科特有表达

**引入观点**
- 就...而言
- 从...角度来看
- 在...语境下
- 基于...理论

**分析表达**
- 体现了...
- 反映出...
- 揭示了...
- 呈现出...

**评价表达**
- 具有...意义
- 存在...局限
- 为...提供了新视角
- 丰富了...的内涵

### 避免的表达

| 避免 | 改为 |
|------|------|
| 我觉得 | 本文认为/笔者认为 |
| 大家都知道 | 学界普遍认为/众所周知 |
| 肯定是 | 可以推断/有理由认为 |
| 绝对正确 | 具有一定的合理性 |
| 完全错误 | 存在值得商榷之处 |

## 四、材料与引用

直接引用、转述和综合引用均须标明出处，并核查原文是否支持对应论点。引用的文学作品、史料、案例、课程材料和学术文献应区分来源类型；所有作为文献引用的来源须按文献模块通过 DOI 验证。课程强制指定但没有 DOI 的文献应暂停并询问用户，不能自行豁免。

引文长短、脚注、参考文献格式和是否需要页码，以 assignment、课程规范或用户确认的格式为准；不套用固定的“40字”分界。写作示例中的作者、书名、年份和页码不得直接复制为真实引文。
## 五、按已确认大纲组织写作

根据题目的作答动作和评分项，选择概念辨析、文本细读、史料分析、观点比较、案例分析或反思等方式。无需自动设置绪论、文献综述、研究方法、创新点、研究局限或未来方向；只有 assignment 要求或论证确实需要时才加入。

每个部分先说明要回答的问题，再用已核查的材料展开分析，最后回扣该部分与总论点的关系。需要讨论不同观点时，准确呈现各方证据，避免只罗列立场。结尾直接回答题目，不加入正文未支持的新结论。

篇幅由 assignment 的严格字数限制、分题限制和 rubric 权重决定，不预设引言占比。大纲写作前由用户确认；每部分写完后展示内容及证据核查情况，等待用户确认再继续。
## 六、质量检查清单

### 论证检查
- [ ] 论点是否明确、可论证？
- [ ] 论据是否充分、可靠？
- [ ] 论证逻辑是否清晰？
- [ ] 是否回应了可能的反驳？

### 结构检查
- [ ] 各部分是否回应题目和评分项？
- [ ] 各部分之间是否有逻辑关联？
- [ ] 是否有重复或遗漏？

### 引用检查
- [ ] 引用格式是否统一？
- [ ] 引用是否有分析评论？
- [ ] 是否存在过度引用？

### 语言检查
- [ ] 是否符合学术语言规范？
- [ ] 专业术语使用是否准确？
- [ ] 是否存在口语化表达？
