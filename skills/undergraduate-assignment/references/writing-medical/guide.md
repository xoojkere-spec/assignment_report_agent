# 医学写作专项

本技能用于医学、生物与临床相关本科作业。先按 assignment、rubric 和已确认大纲确定任务类型与结构；只有真实研究报告需要时，才使用 IMRaD 和对应报告规范。

## 一、按作业类型选择写法

医学主题的 essay、病例分析、文献评述、实验报告和真实研究报告要求不同。先区分课程给定材料、文献中的结果、用户实际获得的数据及尚未取得的数据。不得把课堂案例、示例数值或模拟数据写成真实患者或实验结果。只有 assignment 或真实研究类型要求时，才采用 IMRaD、伦理与注册信息、研究流程图等内容。
## 二、报告规范指南

<EXTREMELY-IMPORTANT>
仅在 assignment 要求报告真实研究，或明确指定报告规范时，核对适用的规范及版本；普通课程 essay 或病例分析不自动套用这些清单。
</EXTREMELY-IMPORTANT>

| 研究类型 | 报告规范 | 核心要求 |
|----------|----------|----------|
| 随机对照试验 | **CONSORT** | 流程图、随机化方法、盲法、ITT分析 |
| 观察性研究 | **STROBE** | 研究设计、参与者、变量、偏倚 |
| 系统综述 | **PRISMA** | 搜索策略、筛选流程、质量评估 |
| 诊断准确性 | **STARD** | 参考标准、盲法、2×2表 |
| 病例报告 | **CARE** | 时间线、诊断推理、随访 |
| 动物研究 | **ARRIVE** | 样本量、随机化、盲法 |

## 三、事实、伦理与结果呈现

### 伦理及注册信息

只有真实研究或 assignment 明确要求时，才报告伦理审批、知情同意、试验注册和利益冲突。逐项核查原始文件及编号；未知或不适用时说明状态，不能填入虚构医院、批准号、注册号或参与者同意情况。课程提供的模拟病例须清楚标明来源和性质。

### 统计方法与结果

统计软件、版本、检验方法、样本量、效应量和置信区间必须与实际分析一致，不套用固定 SPSS 或 t 检验模板。结果表中的数字只能来自已核查的数据或清楚标注的教学示例；教学示例不得进入真实研究结果。按数据类型、课程格式和实际分析选用均值、标准差、中位数、比例及检验统计量。不得从示例 P 值或表格推导实际结论。
## 四、医学术语规范

### P值报告

- P<0.001：直接写 `P<0.001`
- 0.001≤P<0.05：写精确值，如 `P=0.023`
- P≥0.05：写精确值，如 `P=0.156`
- 避免写 `P=0.000`，应写 `P<0.001`

### 数字规范

- 小数点后保留位数一致
- 百分比保留1位小数
- P值保留3位小数
- 置信区间保留2位小数

## 五、按任务适用的检查清单

- [ ] 结构与内容逐项回应 assignment、rubric 和已确认大纲；字数符合已确认的严格限制。
- [ ] 每项医学事实、病例资料、数据和引用有可核查来源；引用文献通过 DOI 验证，且确实支持对应论点。
- [ ] 若报告真实研究，核查适用的报告规范、伦理信息、注册信息及实际分析；不适用的项目不编造。
- [ ] 若使用课程案例、模拟资料或教学示例，明确标识，不作为真实临床或实验发现。
- [ ] 统计结果、图表与正文一致；未实施的分析不写成已完成。
- [ ] 每完成已确认大纲中的一部分，展示给用户确认后再继续。
